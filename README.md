# UNIDAD-2-BASE-DE-DATOS-EJERCICIO-1
Se debe diseñar un modelo entidad-relación (MER) para organizar la información de una biblioteca.

El sistema debe permitir registrar:
- Libros: ISBN, título, año de edición y editorial.
- Ejemplares físicos: código de inventario único y estado de conservación.
- Autores: cada libro puede tener uno o varios autores, y cada autor puede escribir varios libros.
- Usuarios: alumnos y docentes, con su legajo, nombre, correo institucional y teléfono.
- Préstamos: cada préstamo pertenece a un usuario y puede incluir uno o varios ejemplares.
Además, por cada ejemplar prestado se deben registrar la fecha de préstamo, la fecha prevista de devolución y la fecha real de devolución.
